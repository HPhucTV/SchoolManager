# Migration 20260806_0003 — de-scope dữ liệu legacy

Migration này đồng bộ database với phạm vi SchoolManager mới. Đây là migration destructive: bảng/cột đã nghỉ hưu và dữ liệu bên trong sẽ bị xóa.

## Dữ liệu bị xóa

Các bảng:

- `activities`, `teacher_reports`;
- `quiz_battles`, `battle_participants`, `battle_answers`;
- `badges`, `user_badges`, `shop_items`, `purchases`;
- `search_history`.

Các cột `users`:

- gamification: `xp_points`, `level`, `coins`, `streak_days`, `last_active_date`, `equipped_title`;
- synthetic wellbeing: `happiness_score`, `engagement_score`, `mental_health_score`, `status`;
- email preferences: `email_enabled`, `notify_assignments`, `notify_activities`, `notify_surveys`.

Các cột khác:

- `classes.meeting_link`, `classes.online_enabled`;
- `notifications.file_url`, `notifications.file_name`.

Mood journal (`mood_entries`), SOS (`sos_alerts`), coursework, quiz thường, schedule và notification text được giữ.

## Trước khi upgrade

1. Dừng write traffic.
2. Backup database và kiểm tra restore trên database tách biệt.
3. Export dữ liệu legacy nếu tổ chức cần lưu hồ sơ ngoài SchoolManager.
4. Deploy application code tương thích cùng migration.

```bash
pg_dump -U <user> -d <database> > schoolmanager-before-0003.sql
alembic -c alembic.ini upgrade 20260806_0003
```

Sau upgrade, kiểm tra `/health/ready`, đăng nhập ba role và smoke test lớp, bài tập, quiz, schedule, notification, mood/SOS.

## Rollback

`alembic downgrade 20260805_0002` chỉ phục hồi các cột để tương thích schema; nó không thể phục hồi row từ bảng đã drop. Rollback đầy đủ phải restore backup trước migration. Không chạy downgrade production nếu chưa có restore plan đã thử nghiệm.
